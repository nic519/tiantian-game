# 甜甜爱消除 · Web 还原版

基于已解析的 Cocos 2.4.12 小游戏包，还原主棋盘与单机合成流程。原作棋盘贴图、角色与部分图标已复用；未恢复的配置、甜品图标和部分界面采用独立实现。当前不是完整原工程的 Web 导出。

## 运行

需要 Node.js 22.18+，建议 Node.js 24。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。当前工作环境已接入本机现有的开发依赖，可直接执行 `npm run dev`；复制到其他电脑后先运行 `npm install`。

## 独立 HTML 与构建

```sh
npm run build
```

- `dist/`：可部署的静态网站。
- `dist/tiantian-play.html`：图片、样式和脚本全部嵌入的独立文件，可尝试用 Chrome 双击打开，无外部资源依赖。不同浏览器对本地文件存储与 Web Locks 的支持不同；遇到只读或存档错误时，使用上面的 HTTP 开发服务运行。

本地文件版和 HTTP 版属于不同来源，进度不会自动共用，可通过设置中的导出/导入功能转移。

## 可玩内容

- 7×9 棋盘、点击生产、拖拽或点击选择后移动/合成、不同物品交换。
- 烘焙、咖啡、水果 3 条物品链，每条 7 级，2 个生产器。
- 20 份循环订单模板、奖励、等级、3 次小店装扮。
- 体力恢复、生产冷却、金币补给、格子整理。
- 8 格仓库、物品图鉴、音乐与音效开关。
- IndexedDB 自动存档、上一有效备份回退、存档导出导入、Web Locks 单写入会话。
- 键盘：方向键移动焦点，回车选择物品，再移动到目标格回车即可合成或交换；Esc 取消选择。

## 验证

```sh
npm test
npm run typecheck
npm run build
```

当前 26 项自动化测试通过。DOM 模拟测试覆盖三个订单、键盘合成、装扮、设置、指针取消、多指干扰及存档导入互斥；它不等同于真实浏览器或 IndexedDB 端到端测试。

当前执行环境不允许启动 HTTP 监听，浏览器策略阻止 `file://` 打开；没有完成真实浏览器视觉、手机尺寸、实际 IndexedDB 以及帧率验收。下一步需要在正常浏览器环境执行这些检查。

## 项目结构

- `src/game/model.ts`：独立游戏状态和命令规则。
- `src/game/content.ts`：可替换的物品、订单与节奏配置。
- `src/game/storage.ts` / `session.ts`：存档与会话控制。
- `src/game/board.ts`：Canvas 棋盘和输入。
- `src/game/ui.ts` / `art.ts`：页面、弹窗与补绘素材。
- `public/assets/manifest.json`：原作素材与替代素材来源。
- `docs/restoration-differences.md`：与原作的已知差异及验收缺口。
- `analysis/`：此前的包体分析结果，独立于运行项目，不随构建发布。

原作资源的权利归原权利人；本仓库中的素材来源记录用于识别后续替换项。
