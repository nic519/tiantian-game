原作 `configs.bin` 与地图配置仍缺失，以上数值不能视为已恢复的原作参数。万能物品、特殊宝箱、完整剧情和运营活动仍未接入。

## 验证情况

- 已通过：26 项 Node/DOM 模拟测试、TypeScript 类型检查、Vite 构建、独立文件资源内嵌检查。
- 已审查并修复：损坏存档的高 revision 阻止保存、导入和自动保存竞争、读取旧快照后获得写入锁、畸形导入、键盘选中源丢失、多指干扰。
- 不支持 Web Locks 的浏览器保持只读，避免旧页面接管导致数据覆盖；现代 Chrome/Safari 为主要运行目标。
- 尚未完成：真实 IndexedDB 集成、真实浏览器渲染、手机横向溢出、Pointer Capture 行为、音频策略、帧率和持续游玩。
- 阻碍原因：当前环境拒绝 HTTP 监听与浏览器进程启动；浏览器工具明确阻止 file:// 协议，未尝试绕过。

建议实机验收：在 HTTP 服务下，以 320/375/390/430 CSS px 与桌面宽度依次完成生产、拖拽合成、三个订单、仓库存取、刷新恢复及设置导入导出；再开第二标签页验证只读保护。
